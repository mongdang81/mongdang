# 웹앱 아카이브

내가 만든 수업용·학급관리용 웹앱을 모아 보여주는 사이트입니다.
설치나 빌드 없이 그대로 열리는 정적 사이트(HTML, CSS, JS)예요.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `apps.js` | **사이트 이름, 카테고리, 앱 목록** (평소에는 이 파일만 고치면 돼요) |
| `images/` | 앱 썸네일 이미지를 넣는 폴더 |
| `index.html` | 화면 틀 |
| `style.css` | 색, 글꼴, 배치 |
| `main.js` | 앱 목록을 화면에 그려 주는 코드 |

## 새 앱 추가하기

1. 썸네일 이미지를 `images/` 폴더에 넣어요. (세로로 조금 긴 4:5 비율이 잘 어울려요)
2. `apps.js` 를 열고 `APPS = [` 바로 아래에 다음 한 덩어리를 붙여 넣고 내용을 바꿔요.

```js
  {
    title: "앱 이름",
    category: "subject",          // subject = 교과 수업용, class = 학급관리용
    tag: "과목 · 단원",
    url: "https://내-앱-주소",
    image: "images/파일이름.png",  // 이미지가 없으면 "" (자동 표지가 생겨요)
    date: "2026-11-21",
    keywords: "검색에 걸릴 단어들",
  },
```

3. 저장한 뒤 `index.html` 을 브라우저로 열어 확인해요.

## 내 컴퓨터에서 미리보기

`index.html` 파일을 더블클릭하면 바로 열려요.
