# JSA 세트장의 마지막 밤

영화 「공동경비구역 JSA」(2000)를 본 뒤 하는 중학교 3학년 통일 교육 방탈출 수업 게임입니다. 45분 수업 한 차시에 맞췄어요.
설치나 빌드 없이 그대로 열리는 정적 웹 페이지예요.

학생은 판문점 공동 경비 구역을 본뜬 가상의 영화 세트장에 들어간 견습 스태프가 됩니다. 경비 로봇의 탐조등을 피해
소품 상자 4개를 찾고, 4자리 번호로 열어 자료(영화 장면, 역사 자료)를 읽고 문제를 풀면 열쇠를 얻습니다.
열쇠 4개로 필름 보관실 문을 열고 마지막 장면의 자막(결론 문장)을 완성한 뒤, '나의 한 문장'을 남기면 탈출합니다.

| 상자 | 주제 | 영화 장면 | 자물쇠 | 열쇠 낱말 |
|---|---|---|---|---|
| 1. 남측 초소 사물함 | 분단의 현장 (정전 협정, DMZ) | 지뢰를 밟은 밤 | 1953 | 분단 |
| 2. 회담장 서류함 | 선을 넘은 밤 (분단이 낳은 비극) | 총성이 울린 밤, 서로 다른 진술 | 1976 | 비극 |
| 3. 북측 초소 나무 상자 | 선 너머의 이웃 (동질성과 이질성, 균형 잡힌 북한 이해) | 초소의 밤, 넘어오라는 말 | 1991 | 사람 |
| 4. 소품 창고 필름 통 상자 | 다시 잇는 다리 (판문점의 발자취, 평화) | | 2018 | 평화 |
| 필름 보관실 문 | 결론 문장 완성 + 나의 한 문장 | | 2000 | |

결론 문장: "분단의 선은 서로를 적으로 만들고 끝내 비극을 낳기도 했지만, 우리는 선 너머의 이웃을 같은 사람으로 바라보며 평화의 다리를 함께 놓아 간다."

## 45분 수업 흐름
- 도입 5분: 영화 장면 떠올리기, 주소나 QR로 접속, 규칙 읽기
- 방탈출 28분 (기본 제한 시간): 상자 1개에 약 6분, 필름 보관실 3분
- 정리 12분: 결론 문장 함께 읽기, 토의 질문 1~2개, '나의 한 문장' 발표

토의 질문은 교사 화면에 있어요.

## 화면
- 학생 화면: `index.html` (주소 뒤에 `#/?m=28&r=2&s=1` 을 붙이면 제한 시간·로봇 수·빠르기를 정해서 열려요)
- 교사 화면: `index.html#teacher` (처음 PIN `7272`, 열고 나서 바꿔 주세요) — 설정, 학생용 주소와 QR, 수업 흐름과 토의 질문, 정답 미리 보기

## 진행 방식 (제네바 문서고 게임 구조를 따름)
- 주소를 열면 짧은 여는 장면(글 5장면, 약 22초)이 먼저 나와요. '건너뛰기'로 넘길 수 있어요.
- 화면이 작으면 지도를 확대해 학생을 따라가고, '지도' 버튼으로 세트장 전체와 찾은 상자를 볼 수 있어요.
- 상자 근처에 가면 자동으로 '찾았어요'가 뜨고, 3분 넘게 못 찾으면 수첩 버튼이 반짝여요. 길 찾기 힌트를 2단계까지 보면 갈 곳을 가리키는 화살표가 나와요.
- 배경 음악: 세트장에 들어가면 잔잔하고 긴장감 있는 반복곡이 나와요. 위쪽 '🔊 음악' 버튼으로 학생이 끄고 켤 수 있고, 고른 설정은 그 기기에 기억돼요. 음악 파일 없이 브라우저가 직접 연주하는 곡이라 저작권 걱정이 없어요(`game.js`의 Music).

## 규칙
- 출입증 3장. 탐조등에 비치거나 로봇과 부딪히면 1장을 잃고 대기실로 돌아가요. 그림자 속에서는 들키지 않아요.
- 다 잃으면 1분 쉬고 1장으로 다시 시작해요(열쇠와 수첩은 그대로).
- 자물쇠를 3번 틀리면 가장 가까운 문에서 경비 로봇이 9초 동안 출동하고, 다른 로봇도 12초 동안 빨라져요. 그림자에 숨으면 출동한 로봇이 따라오지 못해요.
- 단서 소품의 쪽지에 다음 상자 위치와 자물쇠 번호의 실마리가 있어요. 수첩의 길 찾기 힌트 3단계째에는 번호가 바로 나와요.
- 시간이 다 되면 끝 화면에서 교사 PIN으로 5분을 더 줄 수 있어요.

## 그림과 저작권
배경(`entry_bg.jpg`, `ending.jpg`)과 영화 장면 카드 그림(`scene_*.jpg`, `card_bridge.jpg`)은 Canva AI 이미지로
영화의 장소와 분위기(판문점 회담장, 눈 내린 초소의 밤, 돌아오지 않는 다리)를 새로 그린 것이고,
나머지 그림은 `art/gen.py` 로 그렸어요. 영화 스틸컷, 포스터, 배우 얼굴은 쓰지 않았고,
영화 내용은 수업 토의를 위해 자료 카드에 글로만 짧게 소개했어요.

## 개인 정보
이름이나 학번을 받지 않아요. '견습 스태프 27호'처럼 번호만 자동으로 붙어요.
게임 기록과 학생이 쓴 문장은 그 학생 기기의 브라우저에만 저장되고, 어디로도 보내지 않아요.

## 고치기

- 그림: `art/` 폴더. SVG는 `python3 art/gen.py` 로 다시 만들 수 있고, JPG는 Canva로 만든 그림이에요.
  JPG 그림을 바꾸려면 같은 이름으로 덮어쓰고, 카드에 그림을 붙이려면 `data.js` 카드에 `img: '파일이름'` 을 넣고 `game.js` 의 `PHOTOS` 목록에 이름을 더해요.
- 화면과 규칙 코드: `game.js`, 모양: `style.css`
