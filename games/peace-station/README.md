# 끊어진 철길, 평화역의 마지막 열차

중학교 3학년 도덕 '북한 이해와 통일' 단원 개인별 방탈출 수업 게임입니다.
설치나 빌드 없이 그대로 열리는 정적 웹 페이지예요.

학생은 견습 기관사가 되어 가상의 '평화역'을 돌아다닙니다. 점검 로봇의 탐지등을 피해 보관함 4개를 찾고,
4자리 번호로 열어 자료를 읽고 문제를 풀면 열쇠를 얻습니다. 열쇠 4개로 기관실 문을 열고 결론 문장을 완성한 뒤,
'나의 한 문장'을 남기면 탈출합니다.

| 보관함 | 주제 | 자물쇠 | 열쇠 낱말 |
|---|---|---|---|
| 1. 매표소 금고 | 북한 바로 알기 (경계와 협력) | 1991 | 균형 |
| 2. 전시실 진열장 | 분단이 남긴 것 (이산가족, 분단 비용) | 1985 | 아픔 |
| 3. 만남의 방 우편함 | 먼저 온 이웃 (북한이탈주민) | 1997 | 포용 |
| 4. 화물 창고 공구 상자 | 평화로 가는 길 (남북 합의, 통일 한국의 가치) | 1972 | 평화 |
| 기관실 문 | 결론 문장 완성 + 나의 한 문장 | 2007 | |

## 화면
- 학생 화면: `index.html` (주소 뒤에 `#/?m=35&r=2&s=1` 을 붙이면 제한 시간·로봇 수·빠르기를 정해서 열려요)
- 교사 화면: `index.html#teacher` (처음 PIN `7272`, 열고 나서 바꿔 주세요) — 설정, 학생용 주소와 QR, 정답 미리 보기

## 규칙
- 승차권 3장. 탐지등에 비치거나 로봇과 부딪히면 1장을 잃고 대합실로 돌아가요. 그림자 속에서는 들키지 않아요.
- 다 잃으면 1분 쉬고 1장으로 다시 시작해요(열쇠와 수첩은 그대로).
- 자물쇠를 3번 틀리면 로봇이 12초 동안 빨라지고 탐지등이 길어져요.
- 시간이 다 되면 끝 화면에서 교사 PIN으로 5분을 더 줄 수 있어요.

## 개인 정보
이름이나 학번을 받지 않아요. '견습 기관사 27호'처럼 번호만 자동으로 붙어요.
게임 기록과 학생이 쓴 문장은 그 학생 기기의 브라우저에만 저장되고, 어디로도 보내지 않아요.

## 고치기
- 글(자료 카드, 퀴즈, 힌트, 낱말 풀이, 지도 배치): `data.js` 만 고치면 돼요.
- 그림: `art/` 폴더의 SVG 파일. 같은 이름의 파일로 바꿔 넣으면 돼요.
- 화면과 규칙 코드: `game.js`, 모양: `style.css`
